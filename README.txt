CYBER DEMO - GITHUB PAGES SETUP

FILES
-----
index.html = harmless landing page students see after scanning.
qr.html    = page that displays the QR code.

IMPORTANT
---------
The QR must point to your PUBLIC GitHub Pages URL.

STEP 1
------
Create a public GitHub repository named:

cyber-demo

STEP 2
------
Upload index.html.

STEP 3
------
Go to:
Repository -> Settings -> Pages

Choose:
Source: Deploy from a branch
Branch: main
Folder: / (root)

Save.

STEP 4
------
Wait for GitHub Pages to publish your site.

Your URL will look like:

https://YOUR-USERNAME.github.io/cyber-demo/

Replace YOUR-USERNAME with your GitHub username.

STEP 5
------
Open qr.html and replace:

https://YOUR-USERNAME.github.io/cyber-demo/

with your real URL.

You can also simply use any QR generator and paste the real URL.

SAFETY
------
This demonstration does not collect passwords, OTPs, names,
phone numbers, location, camera data or other personal information.
